# Cat Courier

A little orange cat delivers parcels across the rooftops of a night city.

2D pixel-art platformer for Android, landscape.
Game Development Fundamentals, Assignment 8-9 (RK2), Aizhan Sagatova.

## Controls
- Left / right buttons (bottom-left) - move
- JUMP button (bottom-right) - jump
- Pause button (top-right) - pause menu

On the laptop: A / D or arrows to move, Space to jump, Esc to pause.

## Scenes
- `Assets/Scenes/MainMenu` - title, Play, Quit
- `Assets/Scenes/Level1` - Rooftops level with HUD and pause

## Week 9 status
Main menu, HUD (hearts, fish counter, pause, touch controls) and pause screen.
UI uses Scale With Screen Size (1920x1080, match 1), anchors and a SafeArea panel.
Tested in Device Simulator on 16:9, iPhone with notch and iPad.

Art and pixel font: made for this project.
